Configuração do Supabase

No código, preencha apenas a URL do projeto e a chave pública (publishable/anon). Nunca coloque a chave secreta ou o token administrativo aqui.

Após configurar, confirme no Supabase Authentication → URL Configuration se a URL de redirecionamento do site está permitida e se o provedor Discord está ativo.
